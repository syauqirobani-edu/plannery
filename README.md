# Plannery
Plannery adalah sebuah aplikasi baris perintah berbasis Python untuk mengelola pekerjaan yang bersifat kolaboratif.

## Ringkasan
Plannery adalah sebuah aplikasi kolaborasi sederhana yang memungkinkan pengguna untuk
- melakukan registrasi dan login akun;
- membuat dan mengelola proyek; dan
- memberikan dan mengirimkan tugas.

Aplikasi ini, untuk sekarang, menggunakan berkas teks untuk penyimpanan (bukan basis data) dan dirancang untuk dijalankan sepenuhnya menggunakan terminal.

## Fitur-fitur

### **Fitur Primer**
1. **Sistem Pengguna**
   - Registrasi - Selesai
   - Login - Selesai
   - Status (Pemilik / Admin / Anggota) - Selesai
2. **Sistem Proyek**
   - Membuat Proyek - Selesai
   - Melihat Proyek - Selesai
   - Memperbaharui Proyek - Selesai
   - Menghapus Proyek - Selesai
3. **Sistem Tugas**
   - Membuat Tugas - Selesai
   - Melihat Tugas - Selesai
   - Memperbaharui Tugas - Selesai
   - Menghapus Tugas - Selesai
   - Melacak tenggat - Selesai
   - Memberikan tugas pada anggota - Selesai
4. **Sistem Pengiriman**
   - Mengirimkan tugas yang telah selesai - Belum Selesai
   - Disimpan per tugas dan per proyek - Belum Selesai

### **Fitur Sekunder**
- Pengingat bersifat personal untuk pengguna yang terlalu sering melewatkan tenggat - Belum Selesai
- Pengingat untuk admin/pengguna yang terlalu banyak memberikan tugas pada seorang anggota - Belum Selesai
