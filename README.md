# Plannery
Plannery adalah sebuah aplikasi baris perintah berbasis Python untuk mengelola pekerjaan yang bersifat kolaboratif.

## Ringkasan
Plannery adalah sebuah aplikasi kolaborasi sederhana yang memungkinkan pengguna untuk
- melakukan registrasi dan login akun;
- membuat dan mengelola proyek; dan
- memberikan dan mengirimkan tugas.

Aplikasi ini, untuk sekarang, menggunakan berkas teks untuk penyimpanan (bukan basis data) dan dirancang untuk dijalankan sepenuhnya menggunakan terminal.

## Fitur-fitur

### **Fitur Primer**
1. **Sistem Pengguna**
   - Registrasi - 0%
   - Login - 0%
   - Status (Pemilik / Admin / Anggota) - 0%
2. **Sistem Proyek**
   - Membuat Proyek - 0%
   - Melihat Proyek - 0%
   - Memperbaharui Proyek - 0%
   - Menghapus Proyek - 0%
3. **Sistem Tugas**
   - Membuat Tugas - 0%
   - Melihat Tugas - 0%
   - Memperbaharui Tugas - 0%
   - Menghapus Tugas - 0%
   - Melacak tenggat - 0%
   - Memberikan tugas pada anggota - 0%
4. **Sistem Pengiriman**
   - Mengirimkan tugas yang telah selesai - 0%
   - Disimpan per tugas dan per proyek - 0%

### **Fitur Sekunder**
- Pengingat bersifat personal untuk pengguna yang terlalu sering melewatkan tenggat - 0%
- Pengingat untuk admin/pengguna yang terlalu banyak memberikan tugas pada seorang anggota - 0%
